# ⚡ Palčekovia Teen AI (Pulse AI)

Moderný, neónový a partnerujúci AI spoločník pre dospievajúcich palčekov a mladých ľudí (13 – 18+ rokov).

## 🌟 Hlavné funkcie
* **Rovnocenný tón:** Žiadne infantilné reči ani poučovanie – asistent komunikuje ako skúsenejší kamarát a rovnocenný partner.
* **Škola a štúdium:** Rýchle vysvetľovanie učiva, sumarizácia textov a príprava na skúšky.
* **Sebavedomie a komunikácia:** Tipy a nadhľad pri odpovediach na nevhodné otázky okolia ohľadom výšky.
* **Technológie a záľuby:** Inšpirácia pre programovanie, AI, bezbariérové športy a záujmy.
* **Práca so súbormi:** Možnosť priložiť obrázky, PDF alebo dokumenty k otázkam.

## 🛠️ Použité technológie
* [Python 3.10+](https://www.python.org/)
* [Streamlit](https://streamlit.io/) – webové rozhranie (Dark mode / Cyberpunk style)
* [Google Gemini API](https://ai.google.dev/) (`gemini-2.0-flash`)
